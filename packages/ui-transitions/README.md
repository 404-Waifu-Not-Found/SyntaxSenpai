# @syntax-senpai/ui-transitions

Shared Vue transition components for SyntaxSenpai's animated scene changes.

## Exports

- `TransitionBidirectional`
- `TransitionHorizontal`
- `TransitionVertical`
- `BidirectionalTransition` - deprecated alias for `TransitionBidirectional`

## Notes

- Built for the same UnoCSS/Vue 3 stack as the rest of the shared UI packages.
- No standalone build step is required.
